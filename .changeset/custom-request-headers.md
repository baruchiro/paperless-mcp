feat(api): support custom request headers for Paperless-NGX instances behind an authenticating reverse proxy. A proxy such as Cloudflare Access, an API gateway, or anything expecting a shared secret rejects the MCP server before Paperless ever sees the request, and there was no way to send the credentials it wants. Headers can now be set with `PAPERLESS_EXTRA_HEADERS` (a JSON object), repeated `--header "Name: value"` flags, or the new optional DXT config field, and are applied to every outbound request — list/search calls as well as uploads, downloads and thumbnails, which build their headers separately. Names and values are validated at startup, so a malformed header fails immediately instead of surfacing later as a connection error, and names are compared case-insensitively as HTTP requires. The three headers the client sets itself — `Authorization`, which carries the Paperless-NGX API token, `Accept`, which pins the API version, and `Content-Type`, which follows the request body — are reserved: configuring them is rejected at startup, and configured headers cannot displace them at the request layer either (a per-request override from a library caller still can). Because a redirect off the configured origin would hand the configured headers to whatever answered — `follow-redirects` strips only `Authorization` and cookies, and its `sensitiveHeaders` option is newer than the version axios pins — such redirects are refused while extra headers are set; the check reads the real redirect target, so it holds even when an HTTP proxy from the environment is in use. Because these headers usually carry credentials, a cleartext `http://` base URL is refused whenever extra headers are configured — at startup by the CLI and again by the `PaperlessAPI` constructor for library callers — with loopback addresses exempt for local testing, where a proxy from the environment is bypassed so the request really stays on the machine. Header values are treated as credentials — parse errors name the offending header but never its value.
